1. Le modèle à quatre parties

Le modèle à quatre parties est la structure fondamentale des réseaux Visa et Mastercard. Les acteurs sont :

  • Porteur : détenteur de la carte, client de la banque émettrice.
  • Banque émettrice : émet la carte, gère le compte, autorise les transactions.
  • Commerçant : accepte le paiement via son TPE.
  • Banque acquéreur : gère le terminal du commerçant, reçoit les transactions, reverse le paiement au commerçant.

Le réseau (Visa ou Mastercard) est au centre mais n'est pas une partie à proprement parler — il fournit les règles, l'infrastructure de routing et de clearing.

L'interchange

Commission que la banque acquéreur verse à la banque émettrice pour chaque transaction. Elle compense l'émetteur pour le risque de crédit pris sur le porteur, les coûts de gestion des cartes et les bénéfices apportés au commerçant (augmentation des ventes, garantie de paiement). Mastercard ne réalise aucun profit sur l'interchange.

Scheme fees

Rémunération du réseau (Visa ou Mastercard) pour l'utilisation de son infrastructure. Facturés aux banques membres. S'ajoutent à l'interchange pour former le coût total supporté par le commerçant via son acquéreur.

Flux de rémunération

Commerçant → Acquéreur (MSC = Merchant Service Charge) → Émetteur (interchange) + Réseau (scheme fees) + Marge acquéreur

2. Routing des transactions

Règle GIM-UEMOA vs réseaux internationaux

Pour une carte co-badgée GIM-Visa, la règle de routing intrarégionale prime :

  • Transaction entre deux membres GIM dans la zone UEMOA → Switch GIM-UEMOA (pas VisaNet).
  • Transaction hors zone UEMOA → VisaNet (ou Banknet pour Mastercard).

BIN (Bank Identification Number)

Les 6 premiers chiffres du PAN identifient : le réseau (Visa = commence par 4, Mastercard = par 5 ou 2), la banque émettrice, le type de produit (débit, crédit, prépayée), la zone géographique. Le BIN ou IIN est attribué par le réseau à chaque banque membre.

4. Fichiers de clearing et règlement

Visa

  • EP (Early Processing) : fichier de clearing — détails de toutes les transactions de la journée.
  • VSS (Visa Settlement Service) : fichier de règlement financier — solde net à régler entre banques.

Mastercard

  • IP (Interchange Processing) : équivalent de l'EP Visa pour le clearing.
  • GCMS (Global Clearing Management System) : système de clearing Mastercard.

GIM-UEMOA

  • LIS (Lien Interbancaire Spécifique) : fichier de compensation quotidien produit après le cut-off.

5. Authentification en ligne — 3D Secure

Protocole d'authentification forte pour les paiements e-commerce :

  • Visa : Verified by Visa (VbV)
  • Mastercard : Mastercard SecureCode
  • American Express : SafeKey

La version 3DS 2.0 apporte une authentification basée sur le risque (risk-based authentication) évitant la friction systématique pour les transactions à faible risque.

6. Délais de contestation porteur

Un porteur dispose généralement de 60 jours à partir de son relevé de compte pour contester une transaction et déclencher un chargeback. Au-delà, la réclamation peut être rejetée pour dépassement de délai.

Synthèse : Acquéreur paie interchange à émetteur. EP = clearing Visa. VSS = règlement Visa. 0100 = demande d'autorisation. DE37 = RRN = clé de réconciliation. Code 51 = provision insuffisante.
